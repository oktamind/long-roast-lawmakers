One satirical sentence roasting lawmakers who would regulate AI, crypto or the internet but cannot convert a file to PDF.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes one 184-character sentence to `out/entry.txt`:

> These lawmakers can write 400 pages of law to govern AI, crypto and the internet, yet to turn that same bill into a PDF they print it, scan it, and email you a photograph of the paper.
